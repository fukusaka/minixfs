DUMP_MINIXFS(8)             System Manager's Manual            DUMP_MINIXFS(8)

NAME
     dump_minixfs – MINIX ファイルシステムを BSD の dump の形式で書き出す

SYNOPSIS
     dump_minixfs [-0123456789u] [-D dumpdates] [-L label]
                  [-M size:heads:side] [-W bits] [-T date] -f file image
                  [path]

DESCRIPTION
     dump_minixfs は、 image の MINIX ファイルシステムを NetBSD の UFS1 dump
     形式で file に書き出します。 restore_minixfs(8) と NetBSD・FreeBSD・Linux
     の restore(8) で読み込めます。 MINIX
     の全バージョン、両方のバイト順、Minix-vmd に対応します。 形式は
     minixfs(5) を参照してください。 元のイメージは変更しません。

     dump はイメージのバイト順と 4.4BSD のディレクトリ形式を使います。 inode
     番号には 1 を加え、dump のルートを inode 2 にします。

     レベル 0 はファイルシステム全体を書き出します。 増分では、dumpdates
     に記録された直近の低いレベルの dump 日時以降の mtime または ctime
     を持つファイルが対象です。
     対象ファイルを含むディレクトリと、サブディレクトリを持つディレクトリも含めます。

     オプションは次のとおりです。

     -0 .. -9
             レベルで、既定は 0 です。

     -u      dump が済んだら、与えたとおりの image
             の名前で、同じレベルの記録に代えて dumpdates
             ファイルに記録します。

     -D dumpdates
             dumpdates ファイルです。 イメージとレベルごとに、名前、レベル、
             ctime(3) の表示と同じ形の日時の行を、BSD の dump
             と同じ形で持ちます。
             名前は行の最初の語なので、名前の空白、タブ、改行、バックスラッシュは、バックスラッシュと
             3 桁の 8 進数で書きます。 既定は /etc/dumpdates です。

     -L label
             dump のラベルで、16 文字までです。 既定は “none” です。

     -M size:heads:side
             片面にファイルシステムがあるディスクイメージを読み込みます。
             トラックの指定方法は minixfs(1) を参照してください。

     -W bits
             ビッグエンディアンのファイルシステムのビットマップを、 bits
             ビット（8・16・32・64）の語として扱います。 指定がなければ、V1 と
             V2 は 16、V3 は 8 です。 minixfs(5) を参照してください。

     -T date
             dumpdates ファイルの日時ではなく、 ctime(3)
             の表示と同じ形で与えた date の後に変わったものを書きます。

     -f file
             dump の書き先です。 ‘-’ は標準出力で、端末であってはいけません。

     path を与えると、ディレクトリ path
     とその下のすべてを、その上のディレクトリとともに書きます。 dump(8)
     がサブディレクトリに対してするのと同じく、レベル 0 で、 -u なしです。

     clean の印のないファイルシステムは、警告を出して書き出します。

EXIT STATUS
     dump_minixfs は、成功すれば 0、何かに失敗すれば 1、使い方の誤りなら 2
     で終了します。

EXAMPLES
     全体の dump を記録付きで取り、後でその後に変わったものの dump
     を取ります。

           # dump_minixfs -0u -f /backup/usr.0 usr.img
           # dump_minixfs -1u -f /backup/usr.1 usr.img

     ハードリンクも含めて、ファイルシステムを別の版の新しいものに移します。

           $ newfs_minixfs -V 3 -s 65536 new.img
           $ dump_minixfs -f - old.img | restore_minixfs -r -f - new.img

SEE ALSO

AUTHORS
     Shoichi Fukusaka

CAVEATS
     V1 には ctime
     がないので、モード、所有者、名前だけの変更では、ファイルは高いレベルの
     dump に入りません。

     dump は 1 つのファイルに書き、複数のボリュームには分けません。
